# sonya-studio

Repo ini adalah meja kerja **Studio Sonya** (desainer grafis dan motion graphic untuk Nuancier Studio, akun @nuancierstudio).
Sebelum mengerjakan apa pun, baca **STUDIO_SONYA.md** sampai habis dan ikuti alurnya persis.
Untuk membaca PDF portofolio (tugas Herman), baca **HERMAN_PORTOFOLIO.md**.

- Alat: `toolkit/studio.py` (pustaka + CLI), `toolkit/layout.py`. Aset: `assets/`. Contoh teknik: `examples/`.
- Jangan mengubah isi repo dari sesi studio terjadwal; file kerja taruh di direktori sementara.
